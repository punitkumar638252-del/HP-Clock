# HP Clock — Android packaging

This project is prepared for Android packaging with Capacitor.

## Build on a computer
1. Install Node.js LTS and Android Studio.
2. Run `npm install`.
3. Run `npm run android:add` once.
4. Run `npm run android:sync`.
5. Open Android Studio with `npm run android:open`.
6. Build an APK from Android Studio, or run `npm run android:build` after the Android project has been added.

App ID: `com.hpclock.app`
App name: `HP Clock`
